Does the number of communities depend on resolution?

Louvain has a resolution knob: low values give fewer, larger groups and high values give more, smaller ones. Each row is the mean over 10 random seeds. Modularity Q is always measured at resolution 1 so rows are comparable. “Big” means at least 10 characters.

Would a random network give the same structure?

I rewired the real network 50 times with degree-preserving edge swaps, so every character keeps its number of links but the connections are shuffled. Louvain was run on each. The histogram shows the Q values from the shuffled networks; the red line is the real network.

Do link weights change the communities?

A mutual link (A links to B and B links to A) counts as weight 2, a one-way link as weight 1. I compared unweighted runs with each other (seed noise) and unweighted with weighted runs, using normalised mutual information (NMI, 1 = identical partitions).
