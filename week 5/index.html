ABOUT THE PROJECT

Marvel as a Social Graph

This project explores the Marvel Universe as a network of characters and relationships. We combine graph analysis with natural language processing to investigate both structural and textual similarities between Marvel characters.

DATA STORIES

From Connections to Text

The project investigates Marvel character networks, degree distributions, paths, communities and finally the textual similarity of Wikipedia pages.

METHODS

How Does It Work?

Each Marvel Wikipedia page is converted into a Bag-of-Words representation. Cosine similarity is then used to measure how similar two character pages are.

01 — Wikipedia Text

Marvel character pages are collected from the provided Wikipedia dataset.

02 — Bag-of-Words

Each page is converted into a vector based on the words appearing in the document.

03 — Cosine Similarity

Similarity between character pages is measured using cosine similarity.
