THE PROJECT

Understanding Marvel as a Network

What happens when fictional characters are treated as nodes in a social network?

🕸️ The Network

We represent Marvel characters as nodes and their relationships as edges. This allows us to investigate connectivity, centrality, communities, paths, and other properties of the Marvel social graph.

🧠 The Analysis

Graph algorithms and network measures are used to discover important characters, structural patterns, communities, and differences between the real Marvel network and generated random networks.

📚 The Data

The project uses Marvel character information collected from Wikipedia and analyzes the resulting network using Python, NetworkX, pandas, NumPy, and visualization techniques.

🔬 The Project

Across the project, we explore Marvel through graph construction, network statistics, degree distributions, shortest paths, connectivity, community structure, and natural language processing.
