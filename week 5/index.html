Marvel Text Detective

Can textual similarity help us identify Marvel characters from their Wikipedia pages?

This project explores the relationship between textual similarity and the Marvel character network using Wikipedia page text.

Research Question

Can textual similarity help us identify Marvel characters from their Wikipedia pages?

The idea is to treat each character's Wikipedia page as a text document and compare documents using a simple Bag-of-Words representation and cosine similarity.

How the Text Detective Works

1. Mystery Character

A Marvel character is selected as the mystery character.

2. Wikipedia Text

The character's Wikipedia page is used as the text document.

3. Text Similarity

Words are converted into a Bag-of-Words representation and compared using cosine similarity.

4. Your Guess

Choose the candidate whose Wikipedia page is most textually similar to the mystery character.

Method

The game uses a Bag-of-Words representation. Each Wikipedia page is converted into a vector based on the words occurring in the text.

The similarity between two character pages is then calculated using cosine similarity. A higher cosine similarity means that the two pages share more similar word patterns.

Bag-of-Words

Represents a page by counting the occurrence of its words.

Cosine Similarity

Measures the angle between two text vectors. Values closer to 1 indicate greater textual similarity.

Text Inspection

Shared words are displayed after each round so that the similarity result can be inspected rather than accepted blindly.

Reflection

What surprised me?

Characters that appear related in the Marvel network do not necessarily have the most textually similar Wikipedia pages.

What did I check?

Instead of relying only on numerical similarity scores, I inspected the underlying text and the words shared between pages.

Limitation

Bag-of-Words ignores word order and deeper meaning. Two pages can therefore receive a high similarity score simply because they use many of the same words.

Takeaway

Textual similarity provides a simple way to compare Marvel character descriptions. However, similarity scores should be interpreted carefully because word overlap does not necessarily represent semantic similarity.

The Text Detective game makes this limitation visible by allowing the player to inspect the shared words behind each prediction.
